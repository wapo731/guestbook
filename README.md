Guestbook

A simple static guestbook that lets visitors leave a friendly note. Messages are stored locally in the visitor's browser (localStorage). This is useful as a drop-in static demo or for GitHub Pages hosting.

How to use

- Open index.html in a browser (or enable GitHub Pages on this repository to host it).
- Visitors can add a name and message; messages are saved to the browser's localStorage.
- To clear all messages in a browser, click "Clear all".

Notes

- This guestbook is intentionally client-side only and does not send data to any server. If you want a publicly-shared guestbook, you can integrate a server or use GitHub Actions / Issues as a backend.
