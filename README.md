# Guestbook

This repository contains a simple static guestbook website. It's a single-page HTML/CSS/JS app that stores entries in the visitor's browser using localStorage.

Features
- Add a name and message to sign the guestbook
- Entries are stored locally in the browser (no server)
- Clear local entries

Hosting
- You can host this on GitHub Pages by enabling Pages for the `main` branch (this repository creates a `main` branch with the site files).

Notes
- Entries are stored only in each visitor's browser. If you want a server-backed guestbook that keeps a central list of entries, I can add a Node/Express backend or integrate with a hosted database (Supabase/Firebase).
